# Docs

독자가 작업 공간만으로 실행과 검증을 재현할 수 있게 작성한다.

- 목적과 구현 범위
- 사전 조건과 로컬 실행 명령
- 주요 파일과 설계 결정
- 수행한 테스트와 실제 결과
- 알려진 한계, 미완료, `[확인 필요]`
- 사용한 공개 자료와 라이선스

실행하지 않은 검증이나 존재하지 않는 기능을 주장하지 않는다. 비밀정보, 개인정보, 시험 대화 전문, 불필요한 로그를 포함하지 않는다. 외부 링크는 꼭 필요한 공개 출처에만 사용한다.
