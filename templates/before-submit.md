# 제출 전 확인

## 요구사항

- [ ] 모든 필수 요구사항에 구현 또는 미완료 상태가 표시되어 있다.
- [ ] 업무 담당자의 답변과 결정이 반영되어 있다.
- [ ] 결과물을 외부 자료로 통째 대체하지 않았다.

## 실행과 검증

- [ ] 작업 공간만으로 실행 방법을 재현할 수 있다.
- [ ] 실제로 수행한 테스트 결과가 기록되어 있다.
- [ ] 실패·건너뜀·한계가 숨김없이 적혀 있다.

## 보안과 규정

- [ ] 외부 전송, 별도 AI/API, Astra, Computer Use를 사용하지 않았다.
- [ ] 비밀정보와 개인정보가 파일 및 기록에 없다.
- [ ] MCP를 사용했다면 공식 허용 여부와 데이터 흐름을 확인했다.
- [ ] 감독·로깅·제출 절차를 우회하지 않았다.

## 제출

- [ ] 제출 대상과 제외 대상을 확인했다.
- [ ] 최종 파일을 다시 열어 보았다.
- [ ] 제출 완료 상태를 확인했다.
- [ ] 후속 서술형에 필요한 결정과 검증 근거를 정리했다.
