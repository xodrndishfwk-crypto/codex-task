# 사전체험 체크리스트

## 계정·환경

- [ ] 공식 안내의 로그인 방식과 접속 시간을 확인했다.
- [ ] Codex CLI가 제공 환경에서 실행되는지 확인했다.
- [ ] 터미널, 편집기, 파일 저장, 로컬 테스트가 작동한다.
- [ ] 제출 및 후속 서술형 화면의 흐름을 확인했다.
- [ ] 감독 앱, 신분 확인, 촬영 범위를 공식 가이드와 대조했다.

## 도구 제한

- [ ] 제공 Codex 이외 AI를 사용하지 않도록 준비했다.
- [ ] Astra를 선택하거나 호출하지 않는다.
- [ ] Computer Use를 사용하지 않는다.
- [ ] 외부 전송 기능과 자동 텔레메트리를 사용하지 않는다.
- [ ] MCP는 기본 비활성으로 두고, 필요 시 허용 여부를 먼저 확인한다.

## 공개 저장소

- [ ] 저장소가 공개 상태다.
- [ ] 2차 예선 결과 통지 전까지 공개 유지 계획이 있다.
- [ ] 시험 자료, 비공개 코드, 개인정보, 토큰이 없다.
- [ ] 공개 자료의 출처와 라이선스를 기록했다.
- [ ] 결과물 통째 대체용 코드가 없다.

## 모의 실행

- [ ] 요구사항 정리 → 담당자 질문 → 계획 → 구현 → 테스트 → 문서화 흐름을 연습했다.
- [ ] 제한 시간 안에서 작업 중단 시점을 정했다.
- [ ] Codex 승인 대기·실행 중·완료 상태를 구분하고 중복 요청하지 않는다.
- [ ] Browser 미리보기에서 실제 포트, 경로, 0.0.0.0 바인딩을 확인할 수 있다.
- [ ] 작업 일지로 결정·테스트·한계를 짧게 기록할 수 있다.
- [ ] 후속 서술형은 AI와 복사·붙여넣기 없이 직접 답해야 함을 확인했다.
- [ ] `python scripts/validate_toolkit.py`가 통과한다.
- [ ] 네트워크 없이 템플릿과 스크립트를 사용할 수 있다.
