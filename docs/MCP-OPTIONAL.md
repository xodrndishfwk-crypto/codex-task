# MCP 선택 사용 원칙

MCP는 과제 해결에 필수가 아니다. 기본값은 사용하지 않음이다.

사용 전 다음을 모두 확인한다.

- 최신 공식 규정이 해당 MCP를 허용한다.
- 입력 데이터가 작업 환경 밖으로 전송되지 않거나, 전송이 명시적으로 허용된다.
- 별도 AI 모델이나 금지 서비스를 간접 호출하지 않는다.
- 인증정보를 코드, 로그, 제출물에 남기지 않는다.
- 사용 내역과 결과를 재현 가능한 방식으로 기록할 수 있다.
- MCP 없이 가능한 로컬 대안과 비교해 필요성이 있다.

하나라도 확인되지 않으면 사용하지 않는다. 특히 외부 SaaS, 원격 저장소 쓰기, 원격 브라우저 조작, 분석·텔레메트리 기능은 자동으로 허용된 것으로 간주하지 않는다.
