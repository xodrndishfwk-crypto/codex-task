# 허용되는 것과 금지되는 것

이 문서는 저장소 설계 시 적용한 안전 경계와 원문 재확인이 필요한 항목을 구분한다. 공식 규정의 대체물이 아니다.

## 반영한 명시 조건

- 공개 저장소의 지침, Skill, 하네스, 템플릿, 코드는 상세 가이드 허용 범위 내에서 활용할 수 있다.
- 활용 저장소는 공개 상태여야 하며 2차 예선 결과 통지 전까지 공개 상태를 유지해야 한다.
- 비공개 저장소 사용은 허용되지 않는다.
- 외부 자료로 결과물을 통째 대체할 수 없다.
- 사용 자료, 제출물, 작업 이력이 검토 대상이 될 수 있다.
- 외부 전송, Computer Use, Astra는 사용하지 않는다.
- 제공된 Codex만 사용한다.
- MCP는 선택사항이다.
- 공개 자료는 플랫폼 안에서 Git Clone·다운로드로 가져올 수 있으며 외부 브라우저로 직접 접근하지 않는다.
- Git Push와 문제·파일·작업 결과물의 외부 전송은 금지된다.
- 개인 PC 파일은 업로드할 수 없다.
- 후속 서술형에서는 AI와 복사·붙여넣기를 사용할 수 없다.

## 저장소 설계 대응

| 위험 | 대응 |
|---|---|
| 특정 과제 정답 사전 제작 | 도메인 코드와 완성 앱을 포함하지 않음 |
| 외부 전송 | 업로드, API, 웹훅, 텔레메트리 기능을 포함하지 않음 |
| 금지 AI/도구 호출 | AGENTS.md와 모든 워크플로에 금지 경계 명시 |
| 검증 과장 | 실제 실행 결과, 실패, 미실행을 구분하는 템플릿 제공 |
| MCP 의존 | 기본 비사용, 허용 확인 시에만 선택적으로 사용 |
| 민감정보 공개 | 공개 전 비밀정보와 비공개 자료 점검 항목 제공 |
