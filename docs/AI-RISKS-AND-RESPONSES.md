# AI 사용 시 주의할 위험과 대응 행동 10가지

사용자가 앞선 대화에서 제공한 위험 목록과 대응 행동을 정리한 참고 문서다. 모든 AI가 모든 상황에서 아래 문제를 일으킨다는 뜻은 아니며, 실제 작업의 입력·환경·결과를 근거로 발생 여부를 판단한다.

| AI의 특성·위험 | 발생 가능한 문제 | 사용자가 해야 할 행동 |
|---|---|---|
| ① 할루시네이션 | 없는 데이터·API·결과를 만들어냄 | 원본·실행 결과 대조 |
| ② 과도한 동조 | 사용자의 잘못된 가정도 수용 | 반박·반례 요구 |
| ③ 모호한 조건의 임의 해석 | 최적화 기준을 멋대로 결정 | 요구사항·제약조건 명시 |
| ④ 긴 맥락에서의 정보 누락 | 앞서 제시한 조건 일부를 놓침 | 요구사항 추적표 사용 |
| ⑤ 그럴듯한 논리 구성 | 잘못된 결론에도 설득력 있는 설명 | 독립적 수치 검증 |
| ⑥ 기존 패턴에 의존 | 익숙한 알고리즘만 추천 | 대안 비교 실험 |
| ⑦ 성공 중심의 결과 보고 | 미구현 기능도 완성됐다고 설명 | 실제 실행·테스트 요구 |
| ⑧ 입력에 따른 결과 변동 | 같은 질문에도 다른 제안 | 기준 데이터·설정 고정 |
| ⑨ 도구 사용의 과도한 자율성 | 중요한 파일이나 설정을 임의 수정 | 권한 제한·변경 승인 |
| ⑩ 민감정보 노출 위험 | 직원 주소 등 개인정보 유출 | 가명화·접근 통제 |

이 목록은 사용자 제공 내용을 보존한 것이며, 항목별 외부 자료 검증이나 발생 빈도 평가는 포함하지 않는다.
